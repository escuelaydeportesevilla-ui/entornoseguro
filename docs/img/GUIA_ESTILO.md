# EntornoSeguro · Guía de estilo

## Logo
- Monograma "ES" con dos figuras (adulto azul + menor verde).
- Anillo de 16 pictogramas deportivos.
- Texto "ENTORNO SEGURO" en mayúsculas espaciadas.
- Fondo blanco, esquinas redondeadas (icono de app).

## Paleta
| Uso | Color | Hex |
|---|---|---|
| Azul marino principal (E) | Navy | #0B3057 |
| Azul medio | Azul | #12406E |
| Texto logotipo | Navy oscuro | #00183F |
| Transición | Petróleo | #0D818F |
| Verde principal (S) | Verde | #2FA37F |
| Verde claro | Verde menta | #38AF88 |
| Fondo | Blanco roto | #F8FBFB |

Degradado corporativo: `linear-gradient(90deg, #12406E, #0D818F 55%, #38AF88)`

## Aplicación
- Cabeceras: fondo blanco, filete inferior 3 px con degradado.
- Títulos: navy #0B3057. Subtítulos: petróleo #0D818F.
- Acentos positivos: verde #2FA37F.
- Tipografía: Inter (web) / Calibri o Arial (Word/PDF).
- Informes: logo arriba izquierda, 30 mm; pie con "EntornoSeguro · Ayuntamiento de Camas".
- Estados (✓ ⚠ ✗) mantienen verde/ámbar/rojo semánticos, no corporativos.
